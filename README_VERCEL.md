# 手机模拟器 - Vercel 部署指南

## 一键部署到 Vercel

点击下方按钮即可一键部署：

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/cognitic-ai/pocket-ai-5dba&project-name=pocket-ai&repository-name=pocket-ai-5dba)

## 手动部署步骤

1. 打开 https://vercel.com
2. 点击 "Add New" → "Project"
3. 选择 "Import Git Repository"
4. 粘贴：`https://github.com/cognitic-ai/pocket-ai-5dba`
5. 点 "Import"
6. 点 "Deploy"
7. 完成！你会得到一个 `.vercel.app` 的网址

## 部署完成后

你会得到一个类似这样的网址：
```
https://pocket-ai-5dba.vercel.app
```

分享给任何人，他们都可以在浏览器中使用你的手机模拟器！
